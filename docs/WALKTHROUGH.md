# Walkthrough outline (2 minutes 55 seconds)

Record in your own voice. Keep API keys and environment files off screen. Use the authorized private submission channel for footage showing supplied screenplay content. A screen recording is optional; this outline is not a completed recording.

## 0:00–0:20: problem and scope

Explain the goal: find promising 20–60-second source intervals, with an immediate hook, standalone meaning and unresolved ending. The prototype recommends cuts and does not render video or claim measured customer lift.

## 0:20–0:45: run on a new input

Show New analysis, original demo/upload options and the configured provider without exposing credentials. Run the small public demo using offline mode or the available AI provider. Explain that model configuration is swappable. Do not present a saved run as a newly executed live inference.

## 0:45–1:20: inspect a recommendation

Open the saved full-pack analysis. Show one promo's episode, source segments, duration, hook, ending, unanswered question and rubric. Expand the source events. Explain that overlapping camera and dialogue tracks make a camera boundary potentially unsafe for speech.

## 1:20–1:45: evidence and an actual failure

Show full episode coverage, Quality report and a rejected AI proposal. Explain what the validation catches and what still requires a human editor. Baseline/shortlist validity rates measure structural enforcement, not causal audience improvement.

## 1:45–2:10: real feedback collection

Open Reading experiment and its participant link. Show a text card and the Keep reading action, then the report/export. State that these are actual browser interactions and reading proxies, with unknown outcomes kept distinct from negatives. Avoid creating software-test responses in a real study just to inflate sample counts.

## 2:10–2:40: synthetic learning loop

Open Synthetic demo. Point out its explicit synthetic label. Show cold-start fitting, held-out checks and daily selection versus random control. Switch to No signal or Changing trends to illustrate limits. The current model estimates a probability per candidate; it is not a text embedding model, and simulated differences do not prove customer lift.

## 2:40–2:55: reproducibility and next steps

Show the README, saved model/raw output export and the automated checks configuration. Real-audience training, controlled production rollout and contrastive encoder adaptation are future stages. Finish with the source review and private output bundle ready for submission.
